# Padrão de imagens — Notícias BERG

## Dimensões

Usar preferencialmente apenas dois formatos:

- **Horizontal:** 1200 × 900 px — proporção 4:3
- **Vertical:** 900 × 1200 px — proporção 3:4

## Uso

- **Imagem principal:** 4:3
- **Imagem centralizada:** 4:3 ou 3:4
- **Imagem ao lado do texto:** 4:3
- **Duas imagens lado a lado:** preferencialmente ambas em 4:3
- **Retratos, cartazes e objetos verticais:** 3:4

## Regra geral

Não é necessário criar tamanhos diferentes para celular ou para cada posição da imagem.

O CSS da página faz o redimensionamento automaticamente.

> **Padrão BERG: 1200 × 900 horizontal ou 900 × 1200 vertical.**
